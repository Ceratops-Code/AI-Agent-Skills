## Evidence Analysis Contract

- Within the selected analysis surface, treat named checks, candidate signals,
  and examples as starting coverage rather than an exhaustive limit; do not add
  another public surface or workflow phase.
- Report a confirmed finding only when exact evidence supports the mismatch,
  risk, and owning correction. Report plausible but unverified risks separately.
- Recommend the smallest durable correction at the broadest correct owner and
  name the targeted check that would verify it.
- If no finding remains, state the checked scope and material coverage limits;
  do not imply exhaustive certainty.
